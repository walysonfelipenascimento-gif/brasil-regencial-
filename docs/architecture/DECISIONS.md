# Decisões arquiteturais iniciais

- O projeto é independente da Nexora.
- Nenhum recurso, repositório, banco, chave ou serviço da Nexora pode ser reutilizado.
- Supabase não é requisito inicial.
- O frontend será Next.js + React + TypeScript.
- MapLibre será avaliado para o atlas 2D; Cesium para o modo 3D sob demanda.
- Dados cartográficos só serão publicados com fonte, data, escala e precisão documentadas.
- O mapa não exibirá fronteiras inventadas ou atuais como se fossem históricas.
- A abertura cinematográfica será um filme editado e sincronizado, não uma sequência de slides.
- Publicação exige repositório e serviço de hospedagem próprios.
