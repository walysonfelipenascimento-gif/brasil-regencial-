# Registro de pesquisa histórica

Nenhuma fonte primária foi importada nesta entrega.

Para cada item a ser publicado, registrar:
- Identificador interno
- Título
- Autor ou instituição
- Data
- Tipo de fonte
- URL persistente ou referência bibliográfica
- Direitos de uso
- Trecho ou dado sustentado
- Data de consulta
- Responsável pela revisão
- Estado editorial

Estados: em pesquisa, em revisão, aprovado, publicado.

Não criar depoimentos, documentos, fronteiras ou coordenadas sem evidência.
