# Plano audiovisual — abertura de 5 minutos

## Entregáveis
- Roteiro documental validado
- Storyboard e lista de planos
- Vídeos originais/licenciados
- Narração
- Diálogos dramatizados identificados
- Trilha original/licenciada
- Efeitos sonoros licenciados
- Legendas WebVTT
- Master de alta qualidade
- Versões HLS adaptativas
- Versão leve e transcrição

## Pipeline
Pesquisa → roteiro → revisão histórica → storyboard → produção de planos → gravação de voz → trilha e efeitos → edição → legendagem → exportação → integração → QA.

Não marcar a abertura como concluída enquanto o arquivo final e os controles de reprodução não tiverem sido testados.
